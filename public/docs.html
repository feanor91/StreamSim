Documentation StreamSim

Comment fonctionne StreamSim, et comment programmer ses touches, pour le bureau comme pour les simulateurs : Microsoft Flight Simulator (SimConnect, variables, code avionique WASM), SimHub, et les jeux comme Assetto Corsa ou Le Mans Ultimate.

1. Comment ça marche

StreamSim est composé d'un serveur qui tourne sur le PC, d'une interface de configuration (la fenêtre de l'application PC, ou un navigateur sur http://adresse-du-pc:3210/) et d'un Deck : l'écran de touches affiché sur le téléphone ou la tablette (application Android, ou navigateur sur /deck).

  • Vous configurez les touches sur le PC : chaque touche a une action (ce qu'elle fait) et une apparence (titre, icône, couleur, taille).
  • Quand vous appuyez sur le Deck, il envoie l'ordre au serveur sur le Wi-Fi, et c'est le serveur qui agit sur le PC : il envoie des touches au clavier, ouvre un programme, ou parle au simulateur.
  • Le serveur renvoie aussi au Deck l'état des touches (bascules, valeurs affichées) : une touche peut s'allumer quand le train est sorti, ou afficher la vitesse en direct.

2. Créer et régler une touche

L'interface de configuration comporte trois zones :

  • Bibliothèque (à gauche) : des actions et des touches toutes faites, classées par groupes (repliés par défaut, cliquez sur un titre pour l'ouvrir). Une recherche déplie les groupes qui contiennent un résultat.
  • Grille (au centre) : les touches de la page. Glissez une touche sur une autre pour les échanger, ou sur l'onglet d'une page pour l'y déplacer. Clic droit : tester, copier, dupliquer, déplacer, effacer.
  • Inspecteur (à droite) : les réglages de la touche sélectionnée.
  1. Choisissez une case de la grille en cliquant dessus.
  2. Appliquez une action : cliquez sur un élément de la bibliothèque (il s'applique à la case sélectionnée), ou glissez-le sur la case. Les éléments toutes faites (« Train d'atterrissage », « Batterie »…) arrivent avec leur action et leur apparence déjà réglées.
  3. Réglez l'action dans l'inspecteur (section « Action »). Le type d'action se change à tout moment sans perdre le titre ni l'icône.
  4. Personnalisez l'apparence : titre, icône (emoji, icône Aviation ou image), couleur, et taille (section « Apparence »).
  5. Testez : clic droit sur la touche → « Tester », ou appuyez sur le Deck. L'enregistrement est automatique.
AstucePour créer une touche proche d'une touche existante, dupliquez-la (Ctrl+D) puis modifiez-la.

Pages, profils, dispositions

  • Pages : onglets au-dessus de la grille. Double-clic pour renommer, glissez un onglet pour changer l'ordre (c'est l'ordre du Deck). Il n'y a aucune limite au nombre de pages. Quand elles débordent, des flèches ‹ › font défiler les onglets (la molette de la souris aussi), le bouton + reste toujours visible, et le bouton liste (avec le nombre de pages) ouvre la liste complète avec une recherche : cliquez une page pour l'ouvrir. Sur le Deck, glissez le doigt à gauche ou à droite pour changer de page ; toucher le nom de la page (en haut à gauche, avec ▾) ouvre la liste de toutes les pages, et au-delà de 10 pages les points deviennent un compteur « 3 / 40 » qui ouvre la même liste. Une touche de type Page saute vers une page précise (comme un dossier) : le bouton « Parcourir les N pages… » de son réglage la choisit dans la liste avec recherche.
  • Profils : menu en haut. Le profil sélectionné est celui qu'affiche le Deck. Utile pour avoir un jeu de pages par simulateur.
  • Dispositions : Mini (2×3), Standard (3×5), Plus (4×4), XL (4×8). En portrait, la grille est tournée pour garder des touches presque carrées.
  • Touches fusionnées : inspecteur → Apparence → Taille : une touche peut occuper 2×1, 1×2, 2×2, 4×2… (elle s'étend vers la droite et vers le bas, les cases doivent être libres). Pratique pour un grand sélecteur ou un curseur vertical.
  • Sauvegardes : bouton ↺ en haut à droite. Automatiques (30 gardées), manuelles nommées, restauration annulable, export/import d'un fichier .json pour changer de PC.
  • Raccourcis de l'interface : flèches pour se déplacer, Suppr, Ctrl+C / V / D, Ctrl+Z / Y (annuler / rétablir), Échap.

Icônes et images

Dans l'inspecteur (section « Apparence »), trois onglets :

  • Emoji : une liste, ou un caractère tapé au clavier.
  • Aviation : 36 pictogrammes fournis avec l'application, classés par groupes (train et commandes de vol, feux, pilote automatique, systèmes, radios et divers). Ils sont blancs et prennent la couleur de la touche.
  • Image : vos propres images (PNG, JPG, WebP, GIF, SVG) en couleurs, rangées dans la bibliothèque d'icônes.

La bibliothèque d'icônes

C'est un dossier sur le PC : icons/ dans le dossier des données de StreamSim (%APPDATA%\StreamSim\data\icons sous Windows), avec un sous-dossier par thème, par exemple icons/mon-avion/train.png. Les Decks les affichent en les demandant au serveur (/user-icons/…). Une même image sert à autant de touches que vous voulez.

  • Ajouter : onglet Image → déposez une image (elle est rangée dans le dossier « divers »), ou ouvrez la bibliothèque (menu du profil → Bibliothèque d'icônes) pour choisir le dossier et déposer plusieurs images à la fois.
  • Choisir : onglet Image, ou la bibliothèque (clic sur une icône). Supprimer : le × d'une icône dans la bibliothèque.
  • Exporter / importer : boutons de la bibliothèque, ou entrées du menu du profil. L'export produit un fichier streamsim-icones-….json contenant toutes les icônes ; l'import l'ajoute à la bibliothèque (les icônes identiques sont ignorées, celles qui ont le même nom mais un autre contenu ne sont remplacées que si vous le confirmez). Pour changer de PC : exportez la configuration et les icônes, puis importez les deux.
  • Ranger les images intégrées : les images collées directement dans les touches (versions antérieures) alourdissent la configuration. Le bouton « Ranger les images intégrées aux touches » de la bibliothèque les déplace dans le dossier images-des-touches.

Les icônes fournies avec l'application (dossiers public/icons/aviation/… et public/icons/touches-completes/…) ne se modifient pas : elles sont mises à jour avec l'application.

Raccourci clavier

Deux façons de définir la touche :

  • Enregistrement : cliquez dans la zone « Raccourci », puis appuyez sur la combinaison voulue au clavier (Échap annule). L'enregistrement retient la position physique de la touche : un « A » d'un clavier AZERTY est bien enregistré comme « A ».
  • Manuellement : boutons de modificateurs (Ctrl, Maj, Alt, Win) et liste des touches. Utile pour les combinaisons que le système capte avant le navigateur (Ctrl+W, Win+…).

Répéter envoie le raccourci plusieurs fois de suite (jusqu'à 50, 40 ms d'écart). Pour les jeux qui ignorent la touche, voir le Mode jeu.

Texte

Tape le texte tel quel, en Unicode (accents, emojis). « Valider par Entrée » ajoute un retour à la ligne à la fin.

Logiciel cible (raccourci et texte)

Par défaut, les touches partent vers la fenêtre active. La section « Logiciel cible » permet de viser une fenêtre précise, que StreamSim met au premier plan avant d'envoyer les touches :

  • Application : nom du processus (obs64, chrome, Discord…) ;
  • Titre : texte contenu dans le titre de la fenêtre.

Le bouton ⟳ liste les fenêtres ouvertes. Selon le système : Windows utilise SendInput sans prérequis ; macOS utilise AppleScript (autorisez le terminal dans Réglages › Confidentialité › Accessibilité) ; Linux utilise xdotool (+ wmctrl).

Multi-actions

Une suite d'étapes exécutées l'une après l'autre : raccourci, texte, multimédia, application, site web, commande, commande MSFS, commande SimHub et Pause (durée en millisecondes). Exemple : « démarrage moteur » = commande MSFS, pause 500 ms, autre commande MSFS.

Bascule (deux états)

Une bascule a deux états, chacun avec son titre, son icône, sa couleur. À chaque appui elle envoie l'action de son état puis change d'état ; deux pastilles indiquent l'état courant. Vous pouvez donner deux actions différentes, ou la même action pour les deux états (touche « G » du train, par exemple).

  • L'état est gardé par le PC : téléphone, tablette et écran de configuration affichent le même.
  • Synchronisation avec le simulateur : activez l'option d'état lu dans le simulateur et indiquez la variable (MSFS : SimVar, variable L: ou Input Event ; SimHub : propriété). La touche suit alors l'état réel, même si vous agissez à la souris dans le cockpit. « État 2 si la valeur vaut… » permet de n'allumer la touche que pour une valeur précise (auto-freinage sur MED, par exemple) ; une propriété texte peut être comparée à un texte (rapport « R »).
  • Sans synchronisation, si l'état se désynchronise, un appui long sur la touche change l'état sans rien envoyer (le bouton « Changer d'état » de l'inspecteur fait pareil).

Bouton rotatif

Un bouton rotatif se manipule en glissant le doigt (ou la molette de la souris sur PC) :

  • vers la droite ou le haut = Tourner + ; vers la gauche ou le bas = Tourner −. Chaque cran envoie l'action correspondante. La sensibilité (fine, normale, rapide) règle la distance de glissement par cran ;
  • un appui sans glisser déclenche l'action « Appui » (valider une valeur, engager un mode) ; l'appui long déclenche « Appui long » si elle est définie ;
  • « Afficher une valeur du simulateur » montre en direct une valeur (cap « 275° », altitude « 12 000 ft ») avec suffixe, décimales, zéros devant, signe, etc.

Chacune des trois actions (+, −, appui) est une action ordinaire : raccourci clavier, commande MSFS (événement, variable, Input Event, code), commande SimHub…

Sélecteurs à positionsPour un sélecteur à positions nommées (STOP/IDLE/NORM/FIX), un bouton rotatif dont la valeur affichée est lue dans une variable L: convient bien. Les touches du groupe Rafale : cockpit montrent des exemples : le libellé ou le visuel affiché suit la valeur de la variable.

Curseur

  • Vertical si la touche est plus haute que large (fusionnez-la en 1×3 pour un vrai levier), horizontal sinon.
  • Mode Position (MSFS) : la position est envoyée en continu au simulateur (par exemple THROTTLE_SET de 0 à 16383) et le curseur suit le levier si vous le bougez dans le cockpit.
  • Mode Pas à pas : glisser d'un bout à l'autre envoie un nombre réglable de « + » ou de « − » (raccourcis clavier, commandes…), pour n'importe quel logiciel.
  • Un appui sans glisser déclenche l'action « Appui » si elle existe, sinon le curseur saute à l'endroit touché.

Afficheur

Une touche qui affiche en grand une valeur en direct (vitesse, rapport engagé, temps au tour, altitude…), avec un titre en dessous. La valeur vient de MSFS (SimVar, variable L:, Input Event) ou de SimHub (propriété). Options : suffixe (km/h), décimales, facteur (échelle), zéros devant, signe, format « temps au tour » (1:23.456). Un appui peut aussi déclencher une action.

4. Assetto Corsa, Le Mans Ultimate et les jeux de course

Pour un jeu, StreamSim intervient de deux manières : il envoie des touches au jeu (changer de vue, appeler les stands, boîtier de commandes…), et il affiche les données du jeu grâce à SimHub.

Envoyer des touches à un jeu : le « Mode jeu »

Beaucoup de jeux ne voient pas les touches envoyées par un logiciel : ils lisent le clavier par son code matériel (scancode), image par image, et ignorent une touche qui n'a pas de code matériel ou qui est relâchée aussitôt. C'est exactement ce que corrige le Mode jeu : la touche est envoyée comme le ferait un vrai clavier (code matériel) et maintenue quelques millisecondes.

  1. Créez une touche de type Raccourci clavier et enregistrez la touche que le jeu attend (celle de ses réglages de commandes).
  2. Cochez « Mode jeu (touche envoyée comme un vrai clavier) ».
  3. Réglez au besoin la Durée d'appui (60 ms par défaut, de 10 à 500). Augmentez-la si le jeu manque des appuis ; certaines actions « maintenues » du jeu en demandent davantage.
  4. Mettez le jeu au premier plan et testez depuis le Deck.

Ne pas cocher touche par touche

Menu du profil → « Mode jeu automatique sur les nouvelles touches » : une fois coché, tout raccourci clavier ajouté ensuite a déjà le Mode jeu. Il n'est pas activé par défaut car les autres usages (MSFS, bureautique) n'en ont pas besoin. Les touches déjà créées ne changent pas, et vous pouvez toujours décocher le Mode jeu sur une touche précise. Astuce : activez ce réglage avant de construire le profil du jeu, puis désactivez-le.

Configurer les commandes dans le jeu

  • Dans les réglages de commandes du jeu (Assetto Corsa, Le Mans Ultimate), affectez à chaque fonction une touche libre, de préférence peu utilisée (touches F13 à F24, pavé numérique, combinaisons avec modificateurs).
  • Sur StreamSim, créez la touche avec la même touche. Si le jeu demande d'« appuyer sur une touche » pour l'affecter, appuyez sur la touche du Deck : c'est ce qui vérifie que le Mode jeu fonctionne.
  • Pour une action qui demande un maintien (bouton de démarrage, appel de phares…), allongez la durée d'appui.
  • Pour enchaîner des touches (procédure de démarrage, réglages de stand), utilisez une multi-action avec des pauses.

Afficher les données du jeu

Avec SimHub (voir la section SimHub), le groupe SimHub de la bibliothèque propose des afficheurs prêts à l'emploi : vitesse, rapport, régime, carburant, position, tours, tour en cours, dernier et meilleur tour, niveaux d'antipatinage et d'ABS, répartition de freinage… Une bascule synchronisée peut suivre une propriété SimHub (limiteur de stand, contact, DRS) tout en envoyant la touche du jeu.

Si ça ne marche toujours pas

Vérifications, dans l'ordre
  1. Le jeu est bien au premier plan au moment de l'appui, et en fenêtré sans bordure plutôt qu'en plein écran exclusif.
  2. Le jeu tourne en administrateur ? Windows interdit alors à une application ordinaire de lui envoyer des touches : lancez aussi StreamSim en administrateur (clic droit → Exécuter en tant qu'administrateur).
  3. Le Mode jeu est coché sur cette touche, et la touche correspond à celle du jeu (testez-la dans les réglages de commandes du jeu).
  4. Augmentez la durée d'appui (essayez 100 puis 200 ms).
  5. Dernier cas : le jeu ou son anti-triche (EasyAntiCheat, par exemple) bloque toute entrée envoyée par un logiciel. StreamSim n'a aucun moyen de le contourner, et n'en cherche pas. Utilisez alors les fonctions de boutons ou de macros du jeu, ou un périphérique matériel.

5. Microsoft Flight Simulator (SimConnect)

StreamSim pilote MSFS 2024 (et 2020) directement par SimConnect, l'interface officielle du simulateur. Quand StreamSim tourne sur le même PC que MSFS, la liaison s'établit toute seule dès que le simulateur est lancé (indicateur « MSFS » en vert en haut de l'écran de configuration). Aucun fichier à configurer, les commandes partent même si la fenêtre du simulateur n'a pas le focus, et les touches à bascule affichent l'état réel de l'avion.

L'action Commande MSFS propose quatre modes (barre en haut de l'action) :

ModeCe que ça faitExemple
CommandeEnvoie un événement SimConnect, standard ou propre à l'avion, avec une valeur facultativeGEAR_TOGGLE, HEADING_BUG_SET (valeur = cap), A32NX.FCU_HDG_PUSH
VariableÉcrit une SimVar ou une variable locale L: : Fixer, Basculer (0 ↔ 1), Ajouter un pasL:AZP_RAF_AT_MODE
Input EventActionne une commande de cockpit de MSFS 2024 (avion chargé) : Fixer, Basculer, AjouterLIGHTING_LANDING_1
CodeExécute du code avionique (RPN) via le module MobiFlight WASM : événements H: et B:(>H:AZP_RAF_ALARMS_ACKNOWLEDGE)

Comment choisir ? Essayez dans cet ordre : Commande (l'événement standard existe-t-il ?) → Input Event (l'avion l'expose-t-il ?) → Variable (l'avion lit-il une variable L: ?) → Code (l'interrupteur passe par un événement H:).

Mode Commande (événements SimConnect)

Le menu propose une cinquantaine de commandes standard (train, volets, aérofreins, compensateur, feux, pilote automatique, radios, pause…) classées par groupes, plus les commandes d'un A320 FlyByWire. Pour tout autre événement, choisissez Avancé → Autre événement (saisie libre) et tapez son nom (la casse est normalisée en majuscules). La liste complète des événements standard est dans la documentation du SDK MSFS (« Event IDs »). Valeur sert aux événements qui attendent un paramètre : HEADING_BUG_SET avec 270 fixe le cap sélecté à 270°.

Mode Variable

Nom de la variable + unité + opération :

  • Fixer : écrit une valeur ;
  • Basculer : alterne entre la valeur « allumé » (par défaut 1) et « éteint » (par défaut 0) ;
  • Ajouter : ajoute un pas à la valeur courante, avec minimum, maximum et « boucler » (cap 360 → 1). C'est l'opération d'un bouton rotatif.
Écrire les noms correctement
  • Une SimVar standard s'écrit sans préfixe, en majuscules avec des espaces : APU SWITCH, AUTOPILOT HEADING LOCK DIR, avec un indice si besoin : GENERAL ENG THROTTLE LEVER POSITION:1. N'écrivez pas A: devant : « Variable MSFS invalide ».
  • Une variable locale d'un avion commence par L: : L:A32NX_FCU_AP_1_LIGHT_ON. Un indice se met après : L:AZP_RAF_ENGINE_AUXILIARY_LEVER_POS:1.
  • Unité : number pour la plupart des variables L: ; bool pour un 0/1 ; percent, degrees, feet, knots… pour les SimVars physiques.

Attention : écrire une variable L: ne commande pas toujours l'avion. Si l'avion ne fait que lire la variable pour animer un interrupteur (cas fréquent au Rafale), la valeur change mais la fonction n'est pas déclenchée : il faut alors le mode Code avec l'événement H:.

Mode Input Event

Les Input Events sont les commandes de cockpit que l'avion expose à MSFS 2024. Le champ propose la liste de ceux de l'avion chargé (bouton ◎ pour parcourir). Ils se manipulent comme une variable : Fixer, Basculer, Ajouter. Les Input Events peuvent aussi être lus pour alimenter une bascule ou un afficheur.

L'explorateur MSFS : trouver et tester

Cliquez sur l'indicateur MSFS en haut de l'écran de configuration.

  • La liste montre les Input Events de l'avion chargé, avec une recherche. « Lire » affiche la valeur actuelle. Actionnez un interrupteur dans le cockpit puis relisez : celui dont la valeur change est la bonne commande.
  • En bas, « Lire une variable » lit n'importe quelle SimVar ou variable L: (nom + unité). Le même test valide un nom de variable avant de l'utiliser dans une touche.
  • « Exporter » enregistre la liste des commandes de l'avion.

Trouver les commandes d'un avion : la fenêtre Behaviors

Pour un avion non documenté, MSFS 2024 fournit tout ce qu'il faut :

  1. Activez le mode développeur (Options → Général → Développeurs → mode développeur activé). Une barre de menus apparaît en haut de l'écran.
  2. Menu Tools → Behaviors.
  3. Dans le cockpit, pointez l'interrupteur qui vous intéresse et faites Ctrl+G : la fenêtre Behaviors se place sur ce composant (onglet Inspector).
  4. Dépliez Animations (la variable qui anime l'interrupteur, souvent en O: ou L:) et Update codes (le code exécuté quand on clique).
  5. Onglet LocalVariables (« Variab… ») avec le champ « Filter by variable name » : filtrez sur un mot (APU, ELECTRICAL…), actionnez l'interrupteur, et repérez la variable qui bouge. Décochez « only show variables get/set by this behavior » pour voir toutes les variables.

Dans « Update codes », lisez :

  • (>H:NOM) : un événement déclenché → utilisez le mode Code ;
  • (L:NOM, Enum) / (>L:NOM, Number) : une variable locale lue ou écrite → mode Variable (ou lecture pour synchroniser) ;
  • (O:…) : variable propre au composant (animation d'appui, état interne) : illisible et non écrivable depuis l'extérieur, inutile pour StreamSim.

Afficher ou synchroniser avec une valeur du simulateur

Une bascule (état), un afficheur (valeur), un bouton rotatif (valeur affichée) et un curseur (position) peuvent lire leur valeur dans une SimVar, une variable L: ou un Input Event. Choisissez la source (Variable / Input Event / SimHub), le nom et l'unité. Pour une variable qui vaut 0 à 100 %, ou pour un sélecteur à N positions, l'affichage suit la valeur lue (le libellé ou le visuel de la position courante).

6. Code avionique : événements H: et module WASM

Beaucoup d'avions complexes déclenchent la fonction d'un interrupteur par un événement H: (« HTML event ») que SimConnect ne sait pas envoyer. Le mode Code résout cela avec le module gratuit MobiFlight WASM : StreamSim lui transmet un petit programme (RPN) qu'il exécute dans le simulateur.

Prérequis

  • Le module MobiFlight WASM doit être dans le dossier Community de MSFS. Il est souvent fourni avec l'avion (c'est le cas du Rafale d'AzurPoly). Sinon, il s'installe avec MobiFlight (gratuit).
  • Le journal de StreamSim (menu de l'icône → « Ouvrir le journal ») indique si le module est détecté.

Écrire un code

Le code est du RPN (notation polonaise inverse) : les valeurs d'abord, l'opération à la fin. Ce qu'il faut savoir :

ÉcritureSignification
(>H:NOM)Déclenche l'événement H:NOM (appui d'un bouton, incrément d'un sélecteur…)
5 (>L:NOM, Number)Écrit 5 dans la variable locale NOM
(L:NOM, Number)Lit la variable locale NOM
(L:NOM, Number) 1 + 3 min (>L:NOM, Number)Ajoute 1, borne à 3, réécrit : « position suivante, sans dépasser 3 »
(L:NOM, Number) 1 - 0 max (>L:NOM, Number)« Position précédente, sans passer sous 0 »
(>H:A) (>H:B)Plusieurs actions à la suite

Le plus simple est de copier les lignes (>H:…) de l'Inspector (voir Behaviors) et de les coller dans le champ « Code avionique ». Un code peut contenir plusieurs événements et écritures de variables : par exemple (>H:AZP_RAF_ALARMS_ACKNOWLEDGE) 1 (>L:AZP_RAF_VTLG_PAGE_SWITCH_L, Boolean) acquitte les alarmes et allume le bouton correspondant.

Fonctionnement et limites

  • Le code est envoyé au module à 35 ms d'intervalle au plus : plusieurs crans d'une molette successifs sont bien tous pris en compte.
  • Un code n'a pas de retour : pour connaître le résultat, lisez une variable L: (bascule ou afficheur).
  • Le mode Code n'est disponible que sous MSFS, avec le module installé.

Recette : une touche simple (un appui)

  1. Trouvez le (>H:…) dans l'Inspector.
  2. Bibliothèque → Commande MSFS sur une case.
  3. Mode Code ; collez (>H:NOM).
  4. Titre, couleur, icône.

Recette : une bascule qui suit l'état réel

  1. Trouvez l'événement (>H:…) et la variable L: qui garde l'état (Behaviors → LocalVariables).
  2. Type Bascule ; état 1 et état 2 avec des titres/couleurs différents (par exemple « A/T » et « A/T » allumé en vert).
  3. Action : mode Code avec (>H:…), en cochant « Même action pour les deux états ».
  4. Activez l'état lu dans le simulateur, source Variable, nom L:…, unité number.

Recette : une molette (bouton rotatif)

  1. Type Bouton rotatif.
  2. Tourner + : mode Code (>H:NOM_INC) ; Tourner − : (>H:NOM_DEC) ; Appui : (>H:NOM_PUSHED) si l'avion l'a.
  3. Sensibilité : « Normale » ou « Fine » selon l'avion.

Recette : un sélecteur à positions

Pour un sélecteur dont la position est dans une variable L: (0, 1, 2, 3…) :

  1. Type Bouton rotatif.
  2. Tourner + : mode Code (L:VAR, Number) 1 + 3 min (>L:VAR, Number) ; Tourner − : (L:VAR, Number) 1 - 0 max (>L:VAR, Number) (remplacez 3 par la dernière position).
  3. Cochez « Afficher une valeur du simulateur » : variable L:VAR, unité number.

7. SimHub

StreamSim dialogue avec SimHub grâce au plugin gratuit SimHub Property Server (pre-martin/SimHubPropertyServer).

  1. Téléchargez PropertyServer.dll depuis la page Releases du plugin et copiez-le dans le dossier d'installation de SimHub (SimHub 9.6 minimum).
  2. Relancez SimHub et activez le plugin (Settings → Plugins).
  3. La pastille SimHub de l'écran de configuration passe au vert. StreamSim se connecte à 127.0.0.1:18082 et se reconnecte tout seul si SimHub est relancé (autre PC ou autre port : variables SIMHUB_HOST et SIMHUB_PORT).

Ce que SimHub permet :

  • Afficheurs : la propriété à afficher s'écrit dcp.gd.X (pour DataCorePlugin.GameData.X, par exemple dcp.gd.SpeedKmh) ou avec son nom complet copié dans Available properties de SimHub. Le bouton ◎ charge la liste des propriétés connues. Mise à jour en direct (10 fois par seconde au plus).
  • Bascules synchronisées : l'état de la touche suit une propriété SimHub (limiteur de stand, contact, DRS…). L'action reste au choix, par exemple la touche du jeu.
  • Commande SimHub : déclenche un « Control » SimHub. Donnez-lui un nom libre (par exemple deck.dash) ; dans SimHub, Controls and events, créez un mappage et appuyez sur la touche du Deck quand SimHub attend l'entrée. Modes : appui bref, ou appuyer / relâcher séparés (maintien). Vous pouvez ainsi changer d'écran de tableau de bord ou régler le ShakeIt.
  • Boutons rotatifs et curseurs : leur valeur ou leur position peut aussi venir de SimHub.

Le Rafale montre les quatre modes à l'œuvre. Ses touches sont dans la bibliothèque, catégories Rafale (AzurPoly) et Rafale : cockpit.

9. A320neo FlyByWire et autres avions

La catégorie A320 FlyByWire s'appuie sur la documentation officielle FlyByWire, sans module supplémentaire : boutons SPD, HDG, ALT, V/S, BARO (tourner = régler, appui = enfoncer/managé, appui long = tirer/sélecté), AP1, AP2, A/THR, LOC, APPR, EXPED, FD, LS avec leur voyant, auto-freinage LO/MED/MAX.

Pour tout autre avion, le principe est toujours le même :

  1. Essayez les commandes standard (catégorie MSFS 2024 (SimConnect), une trentaine de touches prêtes).
  2. Si l'avion les ignore, ouvrez l'explorateur pour ses Input Events.
  3. Sinon, cherchez ses variables L: et ses événements H: avec Behaviors.
  4. À défaut, utilisez de simples raccourcis clavier (catégorie Simulation (raccourcis clavier)) qui reproduisent les affectations du simulateur.

11. Référence rapide

Mises à jour

À chaque lancement, les applications vérifient les versions publiées sur GitHub et proposent la mise à jour d'elles-mêmes (PC : « Mettre à jour maintenant » ; Android : « Installer », l'APK transitant au besoin par le PC).

Sécurité

  • Par défaut, seul l'ordinateur hôte peut modifier la configuration ou tester des actions. Les autres appareils du réseau peuvent uniquement appuyer sur les touches déjà configurées.
  • Les requêtes provenant d'autres sites web sont refusées (protection CSRF et DNS rebinding).
  • Les actions « Commande système » s'exécutent avec vos droits d'utilisateur : n'y collez que des commandes que vous comprenez.

Où sont les données ?

Application PC : configuration dans %APPDATA%\StreamSim\data (Windows), sauvegardes dans son sous-dossier backups, journal streamsim.log. Serveur seul : dossier DECK_DATA_DIR.

Cette documentation est servie par le serveur StreamSim à l'adresse /docs : elle est donc toujours à jour avec la version installée, et accessible depuis n'importe quel appareil du réseau.
